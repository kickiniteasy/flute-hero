# Flute Hero UI

Two jobs for type, and one size for controls. If a new control does not fit these, it does not ship.

## Type

- **Fraunces** is display type: the wordmark, place names, album and song titles, the call word, and the Start button.
- **Outfit** is everything else you tap or read as chrome: buttons, eyebrows, blurbs, stats labels, inputs.

## Color

- Cream `#f4ecdf` on near-black `#070605`. Dim cream `#b7ab9b` for secondary lines.
- Gold `#f0c36a` is the accent. Text on gold is `#24180f`.
- One gold action per decision (Start, Keep, an on-toggle). The rest are ghost: cream hairline, translucent fill.
- Red `#d15d4c` is record, or a miss. Clay `#e4b48a` is a weak hit.
- Songs, Flutes, and Free Play are a vertical list on every screen. The route dot, the icon, and the name sit on one line. No blurb. Their route colors stay gold, rose, and blue.

## Controls

- Height is 48px. Radius is a pill. Weight is 560. Label size is 16px Outfit.
- **Icon buttons are circles.** They do not stretch into wide pills. A phone toolbar may grow them up to 72px so the row is full.
- **Word buttons in one row share that row** (Play / Your file / Clear, Keep / Download / Discard, Play again / Songs).
- Start is the only display button: Fraunces, 32px, at least 76px tall, gold.
- Back is a chevron. It leaves the screen you are on. The old “Map” label was the code name for the Songs / Flutes / Free Play screen.

## Rows

- A card, a menu row, and a settings control are the same surface: 16px radius, hairline, raised black.
- Titles inside those rows stay Fraunces. Descriptions under them stay Outfit.
